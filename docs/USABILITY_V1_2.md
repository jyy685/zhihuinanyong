# 1.2.0 可用性任务与验收

## 已实现范围

| 任务 | 实现 |
| --- | --- |
| W01 主窗口 | 根布局使用可伸缩网格，底部目录、开始、停止与状态固定；三个页面有纵向溢出滚动 |
| W02 屏幕与缩放 | 根据屏幕工作区确定大小，预留标题栏/任务栏余量；恢复窗口限制在可用区域 |
| W03 工具栏与表格 | 次要操作进入“更多”，页面工具栏按宽度折行；主列可伸缩，表格保留双向滚动与完整信息提示 |
| W04 对话框 | 教程窄窗口使用步骤下拉替代侧栏，页脚按钮可折行；图片查看、更新说明、详情、窗口设置可滚动 |
| C01 选择体验 | 清除搜索、自然名称/大小等排序、方向标记、已选数量、空结果说明；选择依据稳定文件 ID，不随筛选或排序丢失 |
| C05 Cookie 流程 | 整段复制文本识别、脱敏格式预览、服务器确认、连接页自动收起；更新登录后校验可访问任务 |
| C08 窗口设置部分 | 窗口大小/位置/最大化、分栏比例记忆，可关闭记忆或恢复默认；不包含“关于/诊断导出”等后续任务 |

## Cookie 模糊识别边界

接受输入：浏览器 Cookie 表格（含周围界面文字）、Netscape 导出、Cookie 请求头、cURL 中的 Cookie 字段、Cookie JSON 或夹在其他文字中的 JSON、HTML 中的可见表格、逐行/空格分隔的表格内容。

只识别实际出现的完整登录值。不进行 OCR，不补全省略号，不把页面正文当作有效 Cookie；脚本/样式内容不作为 HTML 可见表格提取。显式来自其他站点的请求或 Cookie 表格会拒绝；同一登录项存在不同值时要求用户重新复制。识别结果不代表登录有效，仍需学校服务器验证。设置与记录不保存原始页面文本或 Cookie 值。

## 验证

- 自动布局检查：640×480、900×600、1024×680、1180×720，分别模拟 100%、125%、150%、200% Tk 字体缩放，共 16 组；检查目录、开始、停止、更新按钮映射且位于窗口客户区内。
- 验证课程、任务、连接三个页面；验证教程导航、图片缩放与详情对话框；长内容通过滚动到达，不承诺所有内容在小窗口同时展开。
- 选择回归：自然名称排序、多条件筛选与跨课程选中状态；Cookie 正例/冲突/其他网站/截断案例；窗口设置写入及重启恢复。
- EXE 离线隔离测试验证绑定资源、实际下载服务及 900×600 小窗口控件。

缩放检查通过 Tk 字体缩放模拟，不等同于在每种实体显示器和 Windows 桌面分辨率下逐台测试。若某台电脑仍有布局问题，提供系统缩放、屏幕分辨率和窗口截图便于定位。
