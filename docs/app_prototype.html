从“应用程序”获取 Cookie

在自己的 Edge 或 Chrome 中登录智慧南雍并打开“我的课程”，然后：

  1. 按 F12（笔记本可能为 Fn+F12）或 Ctrl+Shift+I 打开开发者工具。也可从浏览器右上角菜单 → 更多工具 → 开发者工具进入。
  2. 在开发者工具顶部点击 应用程序 / Application。未显示时点标签栏 »；也可从开发者工具右上角 ⋮ → 更多工具 → 应用程序 打开，或按 Ctrl+Shift+P 搜索 Show Application。
  3. 左侧找到 存储 → Cookie / Cookies，展开后选择 https://lms.nju.edu.cn。右侧会显示名称、值、域、路径等列。
  4. 清空筛选框、取消“仅显示有问题的 Cookie”，点击表格一行后按 Ctrl+A、Ctrl+C 复制各行，再粘贴到正式应用的 Cookie 框。
  5. 若只能复制单行，从 session 和存在的 role_token 行底部 Cookie Value 复制完整值，按 session=完整值; role_token=完整值 拼接。不要复制带省略号的截断值或只复制 _ga。
  6. 正式应用点击“验证并加载课程”。当前脚本则把内容保存到 UTF-8 的 cookie.txt。
