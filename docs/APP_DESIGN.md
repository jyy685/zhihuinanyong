# 智慧南雍课件助手：基础版功能设计

版本：设计稿 v0.2 · 2026-11-10

实施更新：已新增 app.py、lms_app 与单文件 EXE 构建脚本，基础功能可实际联网运行。界面最终采用 Python 内置 Tkinter/ttk，以减小分发依赖；原文 PySide6 与先便携目录版为设计阶段建议，实际交付为 PyInstaller onefile。HTML 文件仍只是历史交互原型，实际应用从 app.py 或 EXE 启动。已实现勾选、筛选、Cookie 导入与教程、后台探测/下载、进度、停止、重试、目录选择、完成文件跳过和本机脱敏任务记录。扫描按课程顺序进行，不实现点击课程优先插队。详细运行与构建说明见 README。

本阶段交付基础功能设计与交互原型。原型使用示例课程和模拟任务，不连接学校网站、不读取现有 Cookie、不实际下载。正式应用按下述设计实施。

当前版本 1.1.0 已进一步加入分步图文 Cookie 教程、两张脱敏截图和图片缩放查看；启动后台检查 GitHub 正式 Release，有更新时显示红点，并支持手动检查与下载入口。原始截图不纳入项目，教程衍生图已遮盖全部 Cookie 值及底部明文。

## 1. 产品形态与范围

面向需要下载本人可访问课程课件的同学，提供中文 Windows 桌面应用。打开应用后依次完成：粘贴 Cookie → 验证并加载课程 → 查看课件 → 勾选 → 选择文件夹 → 下载。普通用户无需安装 Python 或使用命令行。

基础版支持课程与课件复选框、跨课程选择、搜索和学期过滤、下载目录、进度与失败重试。保留目前 PDF 原件/预览回退和可访问的非 PDF 原件下载方式。保留命令行入口，图形界面与命令行调用同一下载核心。

基础版不提供学校账号密码登录、自动采集浏览器 Cookie、视频流下载、PPT 转 PDF、断点续传和客户端自动更新。GitHub 发布应用新版本与客户端内自动更新是不同功能，后者放在后续版本。

## 2. 主窗口

建议初始窗口 1280×820，可缩放，支持中文长文件名。低分辨率时通过区域滚动保证按钮可达。

| 区域 | 内容与行为 |
| --- | --- |
| 顶部 | 应用名、当前连接状态、“连接设置 / Cookie 帮助”按钮 |
| 连接设置 | 多行 Cookie 粘贴框、清空、从文件导入、验证并加载课程、分步帮助；成功后可折叠 |
| 左侧课程栏 | 搜索、学期筛选、课程复选框、名称、已探测课件数、加载/空课程/失败状态 |
| 右侧课件区 | 当前课程名称、文件名搜索、类型筛选、“全选当前结果 / 清空当前结果”，以及复选框、序号、文件名、活动标题、类型、大小、下载方式、状态列 |
| 底部操作栏 | 已选课程数、文件数和已知大小合计；目标目录、“浏览”、开始下载 |
| 下载任务页 | 按课程分组的任务、单文件进度、总完成数、成功/跳过/失败数量、停止、重试失败、打开文件夹 |

课程行的名称用于切换查看，复选框用于批量勾选文件，两者互不替代。选中课程 A 后切换到课程 B，A 中的选择仍然保留。

## 3. 勾选规则

- 所有课件初始未勾选，探测不会自动下载。
- 勾选课程：勾选该课程所有已探测且可尝试下载的文件；尚未加载则先加载，成功后勾选。取消课程勾选则清空该课程选择。
- 课程复选框有未选、部分选中、全部选中三种状态；子文件选择变化同步更新父状态。
- 课程勾选操作不受课件关键词/类型筛选影响；课件工具栏明确标注“全选当前结果”，仅影响当前筛选可见文件。
- 全局摘要包含被搜索隐藏的已选文件；提供“查看已选”和“清空全部选择”。
- 刷新时按 course_id + upload_id 对齐选择；消失的文件移除并提示，新增文件默认未选。
- 标注不能下载原件的 PDF 仍可勾选，标为“尝试预览 PDF”，不能仅依赖 allow_download 跳过。下载时才确认预览可用性。
- 已明确无可用原件的非 PDF 显示“暂不可下载”和原因，禁用复选框；下载方式未知的附件可尝试，失败后说明原因。
- 未选择文件、未设置有效目录、登录未验证时禁用“开始下载”，并在按钮旁显示原因。

## 4. Cookie 入口与新手帮助

默认只在本次运行内存中保存 Cookie。输入框采用多行形式，失去焦点后遮盖内容，提供显式“显示 / 隐藏”和“清空”；不把 Cookie 写进日志、探测清单、设置或 GitHub。

支持粘贴 Cookie 请求头（可含 Cookie: 前缀）、现有浏览器 Cookie 表格、JSON；支持导入 Netscape 文件和原有 cookie.txt。文件导入为用户主动操作，分发包不携带个人 cookie.txt。

主界面显示简版步骤，帮助窗口显示完整教程：

1. 点击“打开智慧南雍”，在自己的 Edge 或 Chrome 中进入 https://lms.nju.edu.cn/user/courses#/，正常登录并确认能看到课程。
2. 按 F12；笔记本可能需要 Fn+F12。也可按 Ctrl+Shift+I，或从浏览器菜单打开开发者工具。
3. 选择开发者工具顶部“应用程序 / Application”。未显示时点击隐藏标签 **»**，或右上角 **⋮ → 更多工具 → 应用程序**；也可按 Ctrl+Shift+P 搜索 Show Application。
4. 在左侧“存储”分组展开“Cookie / Cookies”，选择 **https://lms.nju.edu.cn**，右侧显示名称、值、域、路径等列。
5. 清空筛选框并取消“仅显示有问题的 Cookie”，点击表格行后 Ctrl+A、Ctrl+C 复制表格。粘贴时应是多行表格内容。
6. 回到应用粘贴，点击“验证并加载课程”。表格复制不可用时，从 session 及存在的 role_token 行底部 Cookie Value 复制完整值，按 `名称=值; 名称=值` 形式粘贴，不使用带省略号的截断文本。
7. 完整教程与排查步骤见 [COOKIE_GUIDE.md](COOKIE_GUIDE.md)。当前命令行用户将同样内容保存到 cookie.txt；正式图形版在输入框直接粘贴。

教程内提供纯示例 `session=示例值; other=示例值`，明确不可用于登录。简短提示：Cookie 相当于登录凭证，只粘贴到本地应用，不要发给他人。默认不自动读取剪贴板。

验证先检查格式，再访问课程列表接口。区分“格式错误”“登录已失效”“网络连接失败”“账号没有课程”。收到 HTML 登录页、401 或会话相关响应时不误报为空课程；单一资源 403 仅标记资源失败，不直接推断整个登录过期。成功后显示课程数量，不显示原始凭证。

## 5. 探测与下载流程

验证通过后先显示完整分页课程列表，再后台逐门探测附件。界面显示已探测 N/M 门；可优先探测当前点击课程，其余顺序处理。已完成课程可以浏览、勾选；尚在探测的课程显示状态。基础版在扫描结束或用户停止扫描后允许开始下载，避免共享会话和列表更新冲突。

区分“没有附件”和“探测失败”；部分课程失败不清空其他课程。提供单课程重试。停止探测保留已经完成的课程与选项，未完成课程标为“未探测”，不能误报无附件。

点击开始下载时冻结所选任务与目录，按课程 ID 建子目录，默认顺序下载，避免同时写同名文件。传输显示字节与百分比；总大小未知时显示文件完成数和不定进度。标为“预览 PDF”的任务在执行时重新获取临时地址。

保留旧目录规则 `<用户目录>/<课程ID>/<文件名>`；目录旁说明按课程分文件夹，完成页列出课程名称与目录映射。文件名净化，同名不同文件附加 upload_id；目录可写性在开始前测试。已存在且完整的文件显示“已跳过”，不覆盖。不完整的现有文件标记失败，提供打开目录让用户处理。

每个文件先写 .part，验证后再改正式文件名。PDF 校验文件头、原件大小及传输长度；其他原件检查传输与元数据大小，拒绝 HTML/空响应。预览 PDF 可为转换版本，不能一律按原件大小判断。

停止下载采用协作式取消：当前块结束后停止读流，清理本次临时文件，保留已完成文件，剩余任务标记“已取消”。读取超时设定上限，等待响应时显示“正在停止”，不可承诺瞬间完成。关闭活动窗口时让用户选择继续等待或停止并退出。

失败任务保留错误类型与可读建议。网络超时可有限重试；登录过期时暂停后续请求，引导更新 Cookie，验证通过后重试未完成任务。基础版只支持完整文件重试，不声称断点续传。

## 6. 状态与异常

连接：未连接 → 正在验证 → 已连接 / 格式错误 / 登录失效 / 网络失败。

课程：未探测 → 正在探测 → 就绪 / 无附件 / 探测失败 / 已停止。

文件任务：待下载 → 正在解析地址 → 下载中 → 校验中 → 完成 / 已跳过 / 失败 / 已取消。

错误提示必须有对应动作：更新 Cookie、重新探测、重试文件、另选文件夹或打开所在文件夹。详细日志仅在本机，屏蔽 Cookie、完整请求头和带签名的 URL。

## 7. 实现结构

建议 Python + PySide6 实现桌面界面，沿用 requests 的联网逻辑；通过 PyInstaller 构建 Windows 分发包。优先交付便携目录版，确认资源路径、取消和退出行为后再考虑单文件包。正式版本锁定经测试的依赖版本。

建议模块：

```text
app.py                  图形入口
lms_app/
  ui/                   主窗口、Cookie 帮助、课程/课件模型、任务页
  services/client.py    Cookie、登录验证、课程与附件分页
  services/download.py  原件/预览、校验、进度、取消
  models.py             Course / Attachment / DownloadTask
  workers.py            后台任务与事件传递
  settings.py           本机设置、脱敏日志、任务结果
decode.py               保留命令行入口，逐步改为调用上述服务
tests/                  使用假数据与本地响应验证核心行为
docs/                   设计与使用指南
packaging/              打包配置
```

现有 print/input 不能直接作为图形交互：提取结构化结果、可分类异常和进度/取消回调。UI 主线程只负责显示和操作；网络与写文件放后台，UI 事件使用安全消息传递。基础版每次仅执行一个扫描或下载任务，切换 Cookie 前须停止活动任务；不跨工作线程共享可变 Session。

设置只保存目录、窗口大小、筛选偏好。设置、任务记录和日志放用户本机应用数据目录，分发包目录可只读。目录、文件标识和选择用稳定 ID，而不是会变化的显示序号。历史清单不保存临时预览地址。

## 9. 基础版验收

1. 在无 Python 的目标 Windows 电脑打开分发包，中文界面与资源正常加载。
2. 新用户可按内置指南获取 Cookie；正确输入可加载课程，错误/过期输入显示可操作提示，界面不冻结。
3. 课程与附件分页完整；课程无附件、失败、未探测三种情况可区分。
4. 父子复选框、部分选中、跨课程选择和筛选后全选范围符合本设计，下载任务与勾选一一对应。
5. 自选带中文或空格的目录可下载；已存在文件、重名文件、不可写目录均按规则处理。
6. PDF 原件与预览回退、非 PDF 原件、真实拒绝访问分别验证；单个失败不阻断其他任务。
7. 进度正确；停止后无正式名残缺文件；失败可重试；更换 Cookie 后能继续处理未完成任务。
8. 日志、导出清单、应用分发包和 Git 提交中无 Cookie、临时签名和个人课件。
